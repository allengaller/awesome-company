# Awesome Company 扩展设计文档 — 全球科技行业导航清单

## 项目概述

将 Awesome Company 从 20 家中美互联网巨头扩展为覆盖全球科技行业的顶级导航清单，目标收录约 500 家行业头部公司。范围涵盖互联网、软件、硬件及周边上下游产业链，按行业分类组织，每家公司包含完整的信息维度。

## 公司范围

### 目标规模
- 总计约 500 家公司

### 地区分布
- 中国：~150 家
- 美国：~200 家
- 欧洲：~80 家
- 日韩：~40 家
- 东南亚：~20 家
- 其他地区：~10 家

### 行业分布

**互联网（~200 家）**
- 电商：~60 家
- 社交：~40 家
- 内容/媒体：~50 家
- 游戏：~30 家
- 搜索/工具：~20 家

**软件（~150 家）**
- SaaS：~50 家
- 开发者工具：~40 家
- AI/大模型：~40 家
- 安全/数据库：~20 家

**硬件（~80 家）**
- 消费电子：~30 家
- 芯片/半导体：~25 家
- 服务器/基础设施：~15 家
- 物联网：~10 家

**周边上下游（~70 家）**
- 云服务：~20 家
- 支付/金融科技：~20 家
- 物流/供应链：~15 家
- 广告技术：~15 家

## 信息维度

每家公司包含以下 6 个维度：

1. **集团官网** — 公司官方网站
2. **核心产品/服务** — 主要产品或服务的官方落地页（1-5 个）
3. **技术博客** — 官方技术博客链接
4. **开发者社区** — 官方开发者社区/论坛链接
5. **GitHub Organization** — 官方 GitHub 组织页面（如有）
6. **招聘页面** — 官方招聘/careers 页面（如有）

### 格式规范

- **标题层级**: `#` 项目标题 → `##` 行业大类 → `###` 行业子类 → `####` 地区 → `#####` 公司名
- **条目格式**: 无序列表，加粗标签前缀
- **链接格式**: `[显示名](URL)`
- **多链接分隔**: 同一行多个链接用 ` | ` 分隔
- **语言**: 中国公司用中文标签，国际公司用英文标签
- **缺失字段**: 如果某项信息不存在，直接省略该字段，不留空
- **公司排序**: 每个地区内的公司按字母/拼音排序

### 行业分类定义

**互联网**
- **电商**: 在线零售、B2B/B2C/C2C 交易平台
- **社交**: 社交网络、即时通讯、社区平台
- **内容/媒体**: 新闻、视频、音乐、阅读、知识分享
- **游戏**: 游戏开发、发行、平台
- **搜索/工具**: 搜索引擎、浏览器、效率工具

**软件**
- **SaaS**: 企业级软件服务（CRM、ERP、HR、协作等）
- **开发者工具**: IDE、CI/CD、监控、测试、API 工具
- **AI/大模型**: AI 平台、大语言模型、机器学习框架
- **安全/数据库**: 网络安全、数据库、数据仓库

**硬件**
- **消费电子**: 手机、电脑、智能设备、可穿戴设备
- **芯片/半导体**: CPU、GPU、AI 芯片、存储芯片
- **服务器/基础设施**: 服务器、网络设备、数据中心
- **物联网**: IoT 平台、智能家居、工业物联网

**周边上下游**
- **云服务**: IaaS、PaaS、SaaS 基础设施
- **支付/金融科技**: 支付平台、数字银行、区块链、保险科技
- **物流/供应链**: 物流平台、仓储、供应链管理
- **广告技术**: 广告平台、营销技术、数据分析

## 实施计划

1. **Phase 1**: 建立新结构框架，迁移现有 20 家公司到新分类
2. **Phase 2**: 扩展互联网行业（~180 家新增）
3. **Phase 3**: 扩展软件行业（~150 家新增）
4. **Phase 4**: 扩展硬件行业（~80 家新增）
5. **Phase 5**: 扩展周边上下游（~70 家新增）
6. **Phase 6**: 添加开源社区标准元素，最终审查

## 设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 组织方式 | 行业分类 | 符合 Awesome 社区标准，用户价值最大 |
| 文件结构 | 单文件 | 便于维护和搜索，符合 Awesome 传统 |
| 信息维度 | 6 项 | 在信息丰富度和可维护性之间取得平衡 |
| 公司归属 | 按主营业务 | 跨行业公司按主营业务归属，避免重复 |
| 排序方式 | 字母/拼音 | 便于查找和维护 |
