Make it more complete

清单完全由社区共建。找到一家未被收录的公司？三个步骤，你的名字会出现在贡献者列表里。

  1. 1

    阅读贡献指南

    先看 CONTRIBUTING.md 的格式约定与收录标准。

  2. 2

    按模板新增条目

    在对应类别下，按统一模板补充公司信息。

  3. 3

    提交 Pull Request

    维护者复核后合并，贡献者列表为你署名。
